# Thư mục ảnh của web

Chép ảnh vào đúng thư mục với **đúng tên file** dưới đây là web tự hiện, không cần sửa code.
Danh sách lấy từ `js/cau-hinh.js`. Kiểm tra ảnh còn thiếu: `node cong-cu/kiem-tra-anh.js`.

- Ảnh JPG, mỗi ảnh < 500KB, rộng tối đa 1600px (logo dùng PNG nền trong suốt).
- `dai-dien.jpg`: ảnh ngoài tàu đẹp nhất (thẻ trang chủ, ảnh lớn trang tàu, ảnh chia sẻ link).
- `tau-01.jpg` … `tau-08.jpg`: thư viện ảnh trong và ngoài tàu (không bắt buộc đủ 8).
- `menu/…`: ảnh thực đơn của từng món, hiện khi khách bấm "Xem menu".
- Ảnh cũ (bị gán sai tàu) nằm trong `anh-cu/` để tham khảo, web không dùng.
